TASK SORTER PWA — iPhone + ПК

Что изменено в этой версии
===========================
1. Неразобранные задачи можно удалять ПРЯМО справа в режиме «Создание задач».
   У каждой задачи есть красная кнопка ×. Перед удалением программа спрашивает подтверждение.

2. Быстрое создание:
   - название задачи -> Enter
   - комментарий -> Enter
   - сразу следующая задача
   - Shift + Enter в комментарии = перенос строки

3. Справа — прокручиваемый нумерованный список всех НЕРАЗОБРАННЫХ задач.

4. Отдельный режим «Сортировка задач»:
   - показывается одна задача;
   - нажимаете на нужную папку;
   - задача сразу перемещается;
   - автоматически показывается следующая;
   - есть «Пропустить» и «Удалить задачу».

5. База данных:
   - папки;
   - цвет и описание папки;
   - просмотр задач;
   - полный комментарий к выбранной задаче;
   - удаление задачи;
   - перемещение задачи;
   - при удалении папки её задачи НЕ удаляются, а возвращаются в «Неразобранные».

6. Резервная копия:
   - экспорт всей базы в JSON;
   - импорт JSON обратно.

Хранение данных
===============
Данные хранятся в IndexedDB браузера/веб-приложения НА КОНКРЕТНОМ УСТРОЙСТВЕ.
То есть сама опубликованная программа не содержит ваши личные задачи.

ВАЖНО: периодически делайте «Резервная копия -> Скачать резервную копию».

Установка на iPhone
===================
PWA должна открываться по HTTPS. Самый простой вариант — GitHub Pages.

A. Опубликовать:
1. Создайте аккаунт GitHub, если его нет.
2. Создайте новый репозиторий, например task-sorter.
3. Загрузите В САМ КОРЕНЬ репозитория файлы:
   index.html
   styles.css
   app.js
   manifest.webmanifest
   service-worker.js
   папку icons
   файл .nojekyll
4. Откройте Settings -> Pages.
5. Source: Deploy from a branch.
6. Branch: main, folder: /(root).
7. Save.
8. GitHub выдаст адрес вида:
   https://ВАШЕ_ИМЯ.github.io/task-sorter/

B. Поставить на iPhone:
1. Откройте этот адрес именно в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» / Add to Home Screen.
4. Включите «Открывать как веб-приложение» / Open as Web App, если этот переключатель показывается.
5. Нажмите «Добавить».
6. На рабочем столе iPhone появится иконка Task Sorter.

После первого запуска приложение кэшируется и основные функции работают офлайн.

Запуск и редактирование на ПК
=============================
Файлы можно редактировать в Visual Studio как обычные HTML/CSS/JavaScript.

Для полноценной проверки Service Worker/PWA страницу нужно открывать через HTTP/HTTPS,
а не просто двойным кликом file://.

Если используете GitHub Pages — проще всего тестировать опубликованный адрес в браузере.
