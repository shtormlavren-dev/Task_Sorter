На странице внизу должна появиться зелёная надпись:
«Офлайн-режим готов. Теперь можно отключить интернет.»

Дальше:
1. Safari на iPhone.
2. Открыть ссылку.
3. Дождаться зелёной надписи.
4. Нажать Поделиться -> На экран Домой -> Добавить.
5. Запустить иконку один раз при интернете.
6. Полностью выключить Wi‑Fi и мобильный интернет / включить авиарежим.
7. Закрыть приложение.
8. Снова открыть с иконки.
9. Калькулятор должен продолжить работать.

Важно: открывать именно offline-calc.html, а не старый index.html.
